OGraf Studio 0.32 is out. More of a Photoshop or SVG design stays editable when you import it, and
you now choose which data fields a template offers to Nodos.

<!-- truncate -->

## Designs that stay editable

**Resources → Images → Import PSD** now keeps solid rectangles and simple text as editable Studio
layers, in the same stacking order as in Photoshop. Pixel artwork comes in as image layers, and a
PSD that relies on compositing Studio can't rebuild can still use its saved merged image.

**Import editable SVG** reads common layer names, simple inline colours and letter spacing, and
keeps supported artwork editable. Objects Studio can't edit, such as paths with rounded stroke
caps, come in as separate images, so the design still looks right.

## Choose your Nodos inputs

In **Data → Nodos inputs**, pick which fields become input pins in Nodos. This is separate from
**Data → Operator controls**, which decides what playout can edit. New templates start with no
fields selected for Nodos. Templates you made earlier keep the inputs they had, and imported OGraf
packages keep their selected inputs and value types.
