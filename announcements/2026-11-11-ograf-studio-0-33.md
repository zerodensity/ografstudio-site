OGraf Studio 0.33 is out. You can give layers a stable key that page scripts can find, mark frames
that announce themselves during playback, and save the way you would in any other desktop tool.

<!-- truncate -->

## Find a layer by its export key

Select a layer and set **Export key** in Properties. Scripts on the page can then find that layer
on a live graphic through `graphic.instances[instanceId].layers[exportKey]`, in a single graphic
or a coordinated set. Renaming or moving the layer keeps its key.
[Find a layer by export key](/docs/user-guide/preview-and-export/on-a-website#find-a-layer-by-export-key)
has the details.

## Cues at the frames you choose

Move the playhead, choose **+ Cue** on the Timeline, and give the cue a name and an optional JSON
payload. During real-time playback the exported graphic sends an `ograf-studio-cue` event when it
reaches that frame, so the page around it can react. **Frame Cue Log** in **Preview & Export**
shows the cues as they fire; in an exported preview page, press **D** to show the same log.
Re-export an existing project to add both features to its playback files.

## Saving

**File → Save** now writes to the template or template set you have open, and asks where to save
only the first time. **Save As…** picks a new file, and **Save Template Copy…** saves a separate
editable copy of the active template with its thumbnail.

## Also new

- Text boxes set to **Clip** have horizontal and vertical clipping margins, and with **Auto Size**
  the margin follows the text as bound data changes.
- The standalone server can print setup instructions for AI clients with `--print-setup-prompt`,
  and save its built-in authoring skill with `--export-skill <path>`. The skill is also a separate
  download, `ograf-authoring.zip`.
