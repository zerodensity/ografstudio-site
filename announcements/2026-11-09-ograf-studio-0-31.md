OGraf Studio 0.31 is out. Templates made with AI now keep the prompts behind them, and one export
window handles a single template or a whole set.

<!-- truncate -->

## Prompts that stay with the template

The AI Assistant saves the prompts you send with the template. Reopen it and expand **Saved
prompts** to **Copy** one, or **Use prompt** to load it back into the message box, with or without
an AI provider set up. The prompts travel in the `.ogs` file and in exports, so whoever opens the
graphic later can see how it was made. Prompts from external MCP clients are saved too.

## One export window

**File → Export…** now exports the current template or a whole template set. Choose an OGraf ZIP for
playout, a standalone preview page that opens in any browser, or both. Set your usual choice in
**File → Preferences → OGraf Studio → Export**.

Template set exports show their progress while Studio prepares and checks the files, and **Cancel**
or **Esc** stops them. Once the checks pass, save or download the result. **Save Certified Export…**
saves the same checked files again without rebuilding them.

The standalone page now opens with its controls hidden, for a clean picture. Right-click or press
**D** to show them, and expand **Authoring prompts** to read the saved prompts. Fullscreen hides the
controls and the FPS overlay.

## Safer live data

Chart data from a connection that isn't valid is now stopped before it reaches the chart. A
dual-mode template with a live data connection now starts on the **Real-time playout** export
profile; choose **Dual-mode package** or **Non-real-time render** for scheduled rendering.

## Before you upgrade

- The preview page is no longer inside the `.ograf.zip`. Export it as its own file, or choose
  **Both files**, which is the default.
- Saved prompts are part of the exported files, so anyone you send a graphic to can read them.
- MCP clients and scripts must now send the user's original request as `originalPrompt` when they
  create or reset a project, or add, duplicate or paste a template in a set. Refresh the tool
  schema; the [AI authoring reference](/docs/ai-authoring) has the details.
