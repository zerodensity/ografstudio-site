OGraf Studio 0.40 is out. You can now render a template as a transparent WebM movie or a PNG
sequence, start from complete examples in Project Explorer, and review how branding changes when a
template moves to another set.

<!-- truncate -->

## Export video

**File → Export Video…** renders the current template from Start to End. Choose **WebM video** for a
VP9 movie with the timeline's sound, or **PNG image sequence** for numbered frames in a folder. The
background is transparent unless you turn that off. You set the output size, how long the movie
holds on each Step, and the WebM bitrate, and Studio shows the estimated file size before you
render. WebM export needs a current Chrome or Edge.
[Export video and PNG sequences](/docs/user-guide/preview-and-export/export-video) has every setting.

## One window for OGraf export

**File → Export OGraf…** now opens one window for the whole export: the scope, the files, the playout
mode and the thumbnail. Save the OGraf ZIP, the standalone page, or both into one folder. Tick
**NLE Export (for DaVinci Resolve etc.)** for a package that plays in non-real-time mode over a
transparent background. [Export packages](/docs/user-guide/preview-and-export/export-packages)
describes the window.

## Project Explorer

**File → New…** opens Project Explorer. Start from a blank canvas or a recipe, or browse complete
example projects by category, with search. Cards play a short preview when you point at them, and
**License & Credits** shows each example's terms. Examples open as editable copies. The built-in
ones, and online ones you have opened before, also open without a connection.
[Create a template](/docs/user-guide/get-started/create-a-template) has the details.

## Brand Kit transfer review

Adding a template from another set now opens a review first. Keep the template's own appearance,
adopt the destination set's Brand Kit, or bring the source branding along. Compare the frames before
and after, then apply; one **Undo** takes the whole transfer back.
[Template sets](/docs/user-guide/template-sets/overview) explains the choices.

## For AI agents

An agent connected through MCP can export a WebM with `ograf_export_video` and compare a capture
with a reference picture. The tool list is shorter, at 23 tools, and calls that use the earlier
names keep working. See [AI authoring](/docs/ai-authoring#export-a-webm-video-through-mcp).

## Playback fixes

- Data updates apply while a graphic is still animating in or out.
- In a single graphic's playout, **Take Out** no longer waits for a running Take In or Step change.
- A second **Take In** replays the entrance you authored, and sounds that were skipped no longer
  all play at once.
- Urdu and mixed-direction text keep their joining and reading order during reveals and rolling
  effects.
- Resizing the canvas several times keeps each layer's geometry, including very thin and off-canvas
  layers.
